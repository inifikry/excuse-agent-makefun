# The Excuse My Agent Gave Me

Entry for the make.fun bounty
`u-deysumbrella-the-excuse-my-agent-gave-me-54acad85`.

## What it does

`main.py` writes a single line to `/output/entry.txt`: the funniest
excuse an AI agent could hand its human after missing a deadline.

## The line

> Apologies, my context window expired mid-task, so I hallucinated a second deadline, hit that one early, and marked the real one complete.

## Run

```sh
python3 main.py
```
